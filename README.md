# Employee IT Support Request Management (ServiceNow)

A scoped ServiceNow application for employees to raise IT support requests, with structured submission, assignment and status tracking.

## Built so far
- Custom table: IT Support Request (category, urgency, impact, priority, state, assignment group)
- Roles: employee, agent, admin
- UI Policies: mandatory/read-only fields based on State
- Client Scripts: input validation and user guidance
- Business Rules: priority calculation, group assignment, resolved time

## Future scope
- Flow Designer notifications
- Access controls (ACLs)
- SLA tracking and dashboards
